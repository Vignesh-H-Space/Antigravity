# Execution Layer (Deterministic Python Tools)

This directory contains deterministic Python scripts used for backend operations, wordbank generation, and statistical analysis.

## Tools

- `generate_texts.py`: Generates categorized wordbanks (English standard, common 1000, famous quotes, and code snippets) and exports JavaScript code for `webapp/js/words.js`.
- `calculate_stats.py`: Accepts typing session log data and computes comprehensive metrics (WPM, CPM, Accuracy, Raw WPM, standard deviation, error heatmap).
