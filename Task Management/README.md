## 🌟 Core Architecture & Key Capabilities

### 1. 🌐 5 Cascading Horizons of Execution
Break the cycle of tactical busywork by keeping every task tethered to long-term north stars:
- 🌅 **Daily Tasks**: High-leverage non-negotiable execution wins.
- 📅 **Weekly Milestones**: Tactical weekly sprint deliverables.
- 🗓️ **Monthly Goals**: Strategic initiatives and metric check-ins.
- 🎯 **Quarterly Objectives (OKRs)**: 90-day breakthrough targets.
- 🏆 **Annual Vision & Life Pillars**: 1 to 10-year overarching summit visions.

### 2. 📐 Interactive Eisenhower 2×2 Matrix View
Switch between traditional list view and the strategic 2×2 quadrant:
- 🔴 **Do First** *(Urgent & Important)*
- 🔵 **Schedule / Protect** *(Not Urgent & Important — Strategic Growth)*
- 🟡 **Delegate / Streamline** *(Urgent & Not Important)*
- ⚪ **Eliminate** *(Not Urgent & Not Important)*

### 3. 🧠 Integrated Deep Work Focus Mode
- Fullscreen distraction-free timer (`100vh`, zero scroll).
- Precision steppers (`-5m`/`+5m`), 15m/25m/45m/60m/90m presets, and custom duration (1–360 min).
- **100% Offline Ambient Soundscapes**: Synthesized via Web Audio API (🌧️ Gentle Rain, 🌊 Ocean Waves, 🧠 10Hz Alpha Binaural Tone).

### 4. 🎮 Gamified Leveling & Executive XP Engine
- **50 Executive Levels**: From 🌱 *Apprentice* to 👑 *Master of Execution*.
- **Loss Aversion Shields**: Earn Streak Shields every 7 consecutive days to protect your momentum on missed days.
- **12 Lifetime Achievement Badges**: Unlockable milestones celebrate deep work hours, high-velocity streaks, and quarterly completions.

### 5. 🔁 Habit Cadence Grid & Strategic Alignment Index
- 7-day dot-matrix consistency tracking with midnight auto-resetting cadence.
- Real-time **Strategic Alignment Score (%)** flags orphan busywork tasks disconnected from higher horizons.

### 6. 📄 1-Click Executive Weekly Report Exporter
- Generates a formatted executive debrief document aggregating XP progression, deep work focus hours, habit consistency scores, and goals completed.
- 1-click **Copy as Markdown**, **Download .md**, or **Print/PDF**.

### 7. 🗓️ 12-Month Gantt Roadmap & 🌟 Life's Bucket List
- Interactive Jan–Dec Gantt timeline visualizer with dynamic bar spanning.
- Dedicated Life Bucket List view for lifetime summit dreams and milestone adventures.

## 🚀 Quick Start & Local Run

No build step or `npm install` needed! Tesseract is built with pure Vanilla HTML5, CSS3, and ES6+ JavaScript.

1. **Clone the repository**:
   ```bash
   git clone https://github.com/<your-username>/tesseract.git
   cd tesseract
   ```
2. **Open in Browser**:
   - Double-click `webapp/index.html` or open via VS Code Live Server.

## 🌐 1-Click Free Cloud Deployment

Tesseract is an installable **Progressive Web App (PWA)**:

| Platform | Deployment Method | Time |
|---|---|---|
| **Vercel** | Drag & drop `webapp/` folder on [vercel.com](https://vercel.com) | 30 seconds |
| **Netlify** | Drag & drop `webapp/` folder on [app.netlify.com/drop](https://app.netlify.com/drop) | 30 seconds |
| **GitHub Pages** | Settings → Pages → Deploy from branch `/` or `/webapp` | 1 minute |

Detailed step-by-step instructions are available in [HOSTING_GUIDE.md](HOSTING_GUIDE.md).

## 📱 Mobile Installation (PWA)

1. Open your hosted URL on **iOS Safari** or **Android Chrome**.
2. Tap **"Share"** → **"Add to Home Screen"** (iOS) or **"Install App"** (Android).
3. Launches as a native, full-screen standalone application with offline support.

## 🔒 Privacy & Offline-First

All data lives strictly in your browser's persistent `localStorage`. Zero telemetry, zero external tracking, 100% private. Use the built-in **Export JSON** and **Import JSON** controls to backup or transfer data between devices.
